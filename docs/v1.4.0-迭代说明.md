## 一、本次迭代内容

### 1. 工作台「物料分类占比」环形图
- 统计口径改为**一级大类**（tree roots）的 `totalCount`（含所有子孙分类合计），不再按封装/叶子分类拆分，避免出现两个同名「0603」；
- tooltip 显示「分类名：N 种（占比 X.X%）」，实时计算占比；
- 修复空白问题：
  - Chart.js 改为**本地托管** `frontend/vendor/chart.umd.min.js`（原 CDN 在不稳定网络下会加载失败导致空白）；
  - 数据为空/全 0 时显示「暂无分类数据」空态（不再留空白 canvas）；
  - 首屏、15 秒轮询、window focus、visibilitychange、统计周期切换均会刷新环形图。
- 后端仍走 `GET /api/categories`（MariaDB 实时聚合），无新增接口。

### 2. 物料总览筛选栏改造
| 位置 | 新含义 |
| --- | --- |
| 第 1 个下拉 | **物料状态**：全部 / 有货 / 无货 / 低库存预警 |
| 第 2 个下拉 | **物料分类**：仅一级大类（电阻 169、电容 90…） |
| 第 3 个下拉 | **封装大小**：随所选一级大类（含子孙分类）动态加载，自然排序（0402 < 0603 < 0805…） |
| 第 4 个下拉 | **物料排序**：入库时间（默认）/ 库存最少 / 库存最多 / 领用最多 / 领用最少 |

- 分类过滤自动包含所有子孙分类（选「电阻」即包含 电阻/贴片电阻/0603 下的物料）；
- 分类列显示完整路径（如 `电阻 / 贴片电阻 / 0603`），物料名称后显示「领用 N 次」；
- 领用次数来自后端实时聚合：`GET /api/materials` 每条新增 `borrow_count` 字段（`material_logs.action='borrow'`）；
- 导出 Excel 与当前筛选/排序一致（新增「领用次数」「分类路径」两列）。

### 3. 全局下拉框样式统一
`base.css` 的 `.select` 统一为：`appearance:none` + 自定义 SVG 箭头（右 10px 垂直居中）+ 统一内边距 `0 28px 0 11px` + 36px 高 / 34px 行高，修复箭头、文字、外框不对称；禁用态箭头变浅色；筛选栏下拉与搜索框等高。

### 4. 分类管理树形层级视觉
- 一级主分类字号最大（15.5px / 700），二级中等（13.8px / 600），三级最小（12.5px / 500）；
- 行高、数字列字号随层级递减，一级分类行左侧加品牌色强调条。

### 5. 新增/编辑物料 - 级联分类选择
- 分类字段改为 **一级 → 二级 → 三级** 三个联动下拉；
- 选中上级自动展开下级，最终绑定**最深一级**分类；
- 上级为叶子时下级禁用并提示「无子分类」；未选到叶子时保存提示「请选择完整的分类」；
- 编辑物料时按原 `category_id` 自动回填完整路径；历史分类不在树中时提示重新选择；
- 超级管理员保留「+ 新建子分类」按钮（挂到当前选中父级下，最多 3 级）。

### 6. 登录页封面编辑（仅超级管理员）
- 入口：任意已登录页面 → 右上角退出按钮 →【前往封面编辑】→ `login.html?cover=1`；
- 编辑模式：顶部提示条、登录页 **18 处文案双击就地编辑**（Enter 保存 / Esc 取消）、Logo 点击上传（圆角与默认一致）、阻止误登录；
- 右下角【返回主页面】按钮**仅编辑模式显示**；
- 编辑范围：主标题、副标题、左侧 3 条介绍（标题+描述）、登录卡片标题/说明、账号与密码 label 与 placeholder、登录按钮文字、卡片底部说明、页脚文字、已登录提示；
- 普通用户 / 未登录无法进入编辑模式（前端不渲染 + 后端 PATCH 403 双保险）；
- 旧 `pages/cover.html` 保留为跳转页（访问即跳 `login.html?cover=1`）。

### 7. 权限与风格
- 级联分类、封面文案、Logo、分类增删改等均为**超级管理员**专属（后端 `require_super` 强校验）；
- 其余页面配色、布局、组件风格未改动。

## 三、接口变化

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| GET | `/api/settings` | **公开** | 登录页需要读取标题/社团名/Logo（原为登录可读） |
| GET | `/api/ui-settings/{page}` | **公开** | 页面文案（目前 `page=login`），首次读取自动写入默认文案 |
