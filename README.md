# Linda_ERP · 硬件社团物料台账

> 当前版本：**v1.8.0**（2026-11-27）｜线上：<https://linda.linzetao.online>
> 数据库：**linda_erp_v2**（v1.3.0 迁移后的新库；原库 `linda_erp` 结构与数据完整保留，可随时回滚）

校内硬件社团的轻量化物料 ERP，包含**原生静态前端**与 **FastAPI + MariaDB 后端**。  
后端面向 Raspberry Pi 4B 8GB + Ubuntu 24.04 LTS（ARM64）部署，使用 Docker + Docker Compose v2。

## 快速开始

### 前端（本地预览 / 已对接后端 API）

```bash
node scripts/dev-server.js 8090
```

浏览器打开 <http://127.0.0.1:8090/>。前端登录、物料档案、领用/入库/出库、库存查询、用户管理等数据全部来自后端 API 与 MariaDB，不再使用浏览器模拟数据。

- 本地 8090 预览会自动把 API 指向 `http://10.34.126.41:8088/api`
- 通过 Nginx 8088 访问时为同源 `/api`
- 登录账号由后端「用户管理」创建，JWT 令牌保存在浏览器 localStorage 的会话中

> 接口地址、JWT 鉴权与数据层说明见 [docs/FRONTEND-INTEGRATION.md](docs/FRONTEND-INTEGRATION.md)。

### 后端（树莓派 Docker 部署）

```bash
# 1. 将项目上传到树莓派，如 /opt/linda_erp
# 2. 一键部署（自动生成密钥、建表、启动、健康检查、初始化管理员）
sudo bash scripts/deploy-pi.sh

# 3. 验证（后端只监听 127.0.0.1；前端容器监听 8088）
curl -fsS http://127.0.0.1:8000/api/health
curl -fsS http://127.0.0.1:8088/api/health

# 4. 局域网访问
# 前端：http://<树莓派IP>:8088/
# API 文档：http://<树莓派IP>:8088/api/docs
```

- 后端交付细节（技术栈 / 依赖锁定 / 建表 SQL / 环境变量 / 生产启动 / 持久化 / 端口 / 健康检查 / Nginx / 管理员初始化）：见 **[docs/BACKEND.md](docs/BACKEND.md)**
- 接口文档（运行后）：`http://<树莓派IP>:8088/api/docs`

## 部署更新与缓存

- 前端 HTML/CSS/JS 引用带构建版本（如 `?v=20261121b`），Nginx 对 HTML/JS/CSS 禁用缓存；部署新版本后无需手动清缓存即可生效。
- 若浏览器/网络代理仍显示旧页面，可访问一次带版本参数的地址：`http://<树莓派IP>:8088/login.html?v=20261121b`。
- 登录页左下角版本号来自 `frontend/js/config.js` 的 `version`，可用于确认是否加载了新前端。

## 角色与权限

角色从高到低：**超级管理员 > 管理员 > 普通成员**（后端与前端一致）

> 新增物料时，超级管理员可在分类下拉框直接输入新分类名并自动创建；管理员只能选择已有分类。新增物料填写的初始库存会自动生成一张入库单与补货流水。

| 功能 | 超级管理员 | 管理员 | 普通成员 |
| --- | --- | --- | --- |
| 工作台 / 物料总览 / 详情 / 领用日志 | ✅ | ✅ | ✅ |
| 领用登记（单条 / 批量使用车） | ✅ | ✅ | ✅ |
| 新增 / 编辑物料、库存预警、导出 | ✅ | ✅ | ❌ |
| 分类管理：新增 / 删除分类 | ✅ | ❌ | ❌ |
| 分类管理：查看 / 重命名分类 | ✅ | ✅ | ❌ |
| 用户管理 | 管理全部账号、分配任意角色 | 仅管理普通成员 | ❌ |
| 顶栏铃铛 / 访问记录 | 成员访问通知面板 | 跳转库存预警页 | 不显示 |

## 部署约束落实（树莓派 4B 8GB）

| 约束 | 落实 |
| --- | --- |
| 内存：数据库 2GB / 后端 4GB / 系统预留 2GB | compose `mem_limit: 2g` / `4g`，MariaDB 缓冲池 1GB |
| 磁盘约 25GB | 数据与日志挂载 `./data`，日志滚动限量 |
| 国内网络、无法直连 Docker Hub/GitHub 大文件 | `IMAGE_PREFIX` 国内镜像前缀 + 清华 pip 源，依赖均为小体积 PyPI 包 |
| 禁止 SQL Server/Oracle/Elasticsearch/GPU/x86 包 | 仅 MariaDB 10.11 + Python 依赖，全部 ARM64 可用 |
| 数据库仅 MariaDB/PostgreSQL，优先 MariaDB 10.11 | 使用 MariaDB 10.11 |

## Git 版本管理

功能开发完成后手动提交并推送：

```powershell
.\scripts\git-push.ps1 -Message "feat: 本次改动说明"

# 重大迭代同时打版本标签
.\scripts\git-push.ps1 -Message "release: v1.1.0" -Tag v1.1.0
```

首次关联远程仓库（GitHub 私有仓库 `Linda_ERP`）：

```powershell
.\scripts\git-push.ps1 -Message "chore: 初始化仓库" -RemoteUrl "https://github.com/<你的账号>/Linda_ERP.git"
```

规范：不自动实时提交；每次功能完成后手动执行一次提交。
